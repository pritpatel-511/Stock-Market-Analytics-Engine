# 📈 Stock Market Analytics Engine

A professional **Stock Market Data Analysis** project built using **Python** and **NumPy**.

This project analyzes historical stock market data for multiple companies and generates detailed financial statistics, trend analysis, volatility reports, and company rankings.

The goal of this project is to demonstrate strong **NumPy**, **data analysis**, and **software engineering** skills without relying on Pandas or other high-level libraries.

---

# 🚀 Features

## Data Loading

- Load multiple CSV files automatically
- Validate dataset
- Detect invalid rows
- Detect duplicate dates
- Handle missing values
- Validate stock prices

# 📊 Dataset

Each CSV file contains one year of historical stock market data.

Columns:

| Column | Description |
|----------|-------------|
| Date | Trading Date |
| Open | Opening Price |
| High | Highest Price |
| Low | Lowest Price |
| Close | Closing Price |
| Volume | Trading Volume |

# ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/yourusername/Stock-Market-Analytics-Engine.git
```

Go to the project folder

```bash
cd Stock-Market-Analytics-Engine
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
